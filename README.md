# 羽球直播計分板

## 修改對戰名單

所有名單都集中在 `scoreboard-env.js` 的 `MATCH_SCHEDULE` 環境變數。每一行代表一場：

```text
場次|項目|藍隊選手（以、分隔）|黑隊選手（以、分隔）
```

例如：

```text
1|男雙|楊桃、彭博|胖、萊恩
2|混雙|bo、彭丸|宜家、全哥
3|男雙|小宇、斑馬|
```

若選手尚未決定，最後一欄可以留空，畫面會顯示「待定」。`CURRENT_MATCH` 是第一次開啟、尚未有同步資料時的預設場次。

控制頁切換場次後，Firebase 會同步目前場次、對戰姓名與比分，直播顯示頁不必改網址或重新整理。各場比分會分開保存，切回先前場次時仍會保留。

- 控制頁：`index.html`
- 直播顯示頁：`index.html?view=display`
- 不同同步房間：在網址加上 `?match=房間名稱`；直播頁則使用 `?match=房間名稱&view=display`
